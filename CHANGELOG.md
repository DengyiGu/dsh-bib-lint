# Changelog

## 0.1.0 - 2026-11-13

- Added four read-only tools: bibliography audit, reference formatting, revision comparison and DOI lookup.
- Added offline checks and optional Crossref metadata and retraction comparisons.
- Added approximate GB/T 7714, APA, IEEE and Vancouver formatting.
- Preserved full author names and publication details in DOI lookups.
- Rejected malformed input and duplicate keys during formatting and comparison.
- Added configurable lookup budgets, request cancellation and issue limits.
- Packaged as a DSH bundle with no build step, install scripts or extra runtime dependencies.
